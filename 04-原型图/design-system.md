# 设计系统 · 高校勤工助学岗位与考勤管理系统

> 视觉方向：理性学院蓝。目标是"单位内部真实业务系统"的观感——信息密度高、状态可辨、操作路径短。
> 全部页面共用 `assets/style.css`，实现阶段 1:1 复刻本文件的变量与组件尺寸。

## 1. 色彩

| 用途 | 变量 | 色值 | 使用位置 |
|---|---|---|---|
| 主色 | `--pri` | `#173B57` | 顶部栏、侧边栏底色、主按钮、关键数字 |
| 辅助色 | `--sec` | `#287271` | 次级按钮、筛选选中态、进度条、普通图表系列 |
| 页面背景 | `--bg` | `#F4F7F9` | 内容区底色，卡片与表格为白色容器 |
| 强调色 | `--acc` | `#2F6B8A` | 链接、信息提示、图表对比系列 |
| 成功 | `--ok` | `#287D4F` | 已完成 / 已通过 / 正常 |
| 危险 | `--dan` | `#B42318` | 驳回 / 超时 / 异常 / 删除，只做小面积 |
| 主文本 | `--text` | `#1B2A35` | 正文、表格内容 |
| 次文本 | `--text2` | `#5A6B77` | 表头、标签、说明 |
| 弱文本 | `--text3` | `#8A99A5` | 占位、辅助信息 |
| 分隔线 | `--border` | `#DFE7EC` | 卡片边框、表格行线 |

状态**不得只用颜色**表达，必须同时给中文标签（`.tag` 系列）。

## 2. 字体与字号

- 字体栈：`-apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif`
- 数字列统一 `font-variant-numeric: tabular-nums`（`.num` 类），保证金额、工时、评分纵向对齐

| 层级 | 字号 | 字重 | 场景 |
|---|---|---|---|
| 页面标题 | 18px | 600 | 卡片区上方主标题 |
| 卡片标题 | 14px | 600 | `.card-h h2` |
| 正文 / 表格 | 13px | 400 | 默认 |
| 表头 / 标签 | 12–13px | 500 | `th`、`.tag` |
| 辅助说明 | 11–12px | 400 | `.muted` |
| 关键指标 | 22–30px | 600 | `.stat .v`、匹配总分 |

行高 1.6；段落间距 8px 的倍数。

## 3. 圆角、阴影、间距

- 圆角：卡片 / 输入框 / 按钮 `7px`，标签胶囊 `11px`，头像 `50%`
- 阴影：**只用于抽屉与弹窗**（`0 18px 50px rgba(8,24,36,.32)`）；卡片一律用 1px 边框，不用阴影
- 间距基数 4px：卡片内边距 16/18px，内容区外边距 24px，卡片间距 16px
- 栅格：统计卡 6 列（1440 宽下每列约 200px），双栏 1:1，三栏 1:1:1

## 4. 布局骨架

- 侧边栏 220px（折叠 64px），顶部栏 56px，内容区自适应
- 菜单按业务域分组：工作台 / 岗位与申请 / 录用与排班 / 考勤与工时 / 补贴与评价 / 配置与统计 / 系统
- 顶部栏只放面包屑、日期、消息、头像；不放宣传语
- 表单标签宽 120px，单列输入 360–520px，搜索下拉 180–240px

## 5. 角色视觉区分

| 角色 | 骨架 | 差异点 |
|---|---|---|
| 学生 STUDENT | 门户式：顶部导航 + 内容流，卡片化 | 隐藏侧边栏，岗位广场用卡片列表；移动端优先 |
| 用工部门老师 DEPT | 后台：侧边栏 + 顶栏 | 侧边栏主色 `#173B57`，菜单仅本部门业务 |
| 资助中心管理员 ADMIN | 后台：侧边栏 + 顶栏 | 多出配置与统计菜单，顶栏带"审批"红点角标 |
| 财务审核员 FINANCE | 后台：侧边栏 + 顶栏 | 侧边栏底色换 `#1F4A5C`，只读为主，操作按钮单色 |

## 6. 图表

- 系列色序：`#173B57` → `#287271` → `#2F6B8A` → `#8A99A5` → `#7FB2C9`
- 柱状图圆角 4px（仅顶部），折线 2px，环图内径 62%
- 网格线 `#EDF2F5`，坐标轴文字 11px `--text3`
- 首页固定 6 个指标 + 5 个图表，1440×900 一屏内完整可见

## 7. 交互约定

- 状态流转、审批、人工修正一律走右侧抽屉（480px），抽屉内固定展示单据摘要
- 危险操作红色描边 + 二次确认；普通取消无强提醒
- 列表加载 >300ms 显示表格骨架；空状态给"原因 + 下一步"
- 所有时间显示 `yyyy-MM-dd HH:mm:ss`，由全局 `formatTime` 统一处理
